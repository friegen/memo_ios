## 説明文（593 / 4,000 文字）
```
Irodori Notes 是一款可以為文字加上顏色、用彩色資料夾整理記事的簡單記事本。「Irodori」在日文中是「增添色彩」的意思。
隨時都能看到目前寫了多少字，很適合用來寫報告、作文、社群貼文和履歷的草稿。

■ 為文字加上顏色
・10 種文字顏色，還有粗體、斜體、底線
・只把重點換個顏色，記事一眼就能看懂

■ 字數一眼就知道
・隨時顯示每則記事的字數和行數（不計算換行，表情符號也算 1 個字）
・選取文字時，也會顯示選取範圍的字數
・每則記事最多可寫 10 萬字

■ 用彩色資料夾整理
・每個資料夾都能從 10 種顏色中選擇
・資料夾裡也能建立資料夾（最多 5 層）
・可依更新日期、建立日期、字數、名稱等排序
・常用的記事和資料夾可以釘選在最上方

■ 重要記事可以鎖定
・可設定用 Face ID、Touch ID 或 iPhone 密碼開啟
・開啟已鎖定的記事時，App 切換器中不會顯示內容

■ 以 PDF、圖片、文字匯出
・可匯出為 PDF、圖片 (PNG)、文字、含格式的文字 (HTML)，並直接分享

■ 其他功能
・垃圾桶（30 天內可以還原）
・深色模式，可調整文字大小和行距
・支援 iCloud 備份（換新 iPhone 時也能帶走記事）

■ 隱私權
記事儲存在你的裝置中，不會傳送到開發者的伺服器。

本應用程式為免費應用程式，會顯示廣告。
```
